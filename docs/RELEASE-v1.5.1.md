修复自动更新下载完成后提示「更新文件目录不匹配，已停止替换」的问题。

- 程序目录和当前 exe 的父目录统一规范化后再比较，忽略末尾目录分隔符，避免把同一目录误判为不同目录。
- 更新暂存目录仍严格限定在本程序 DevUpData/updates 下的直接 GUID 子目录，保留哈希、大小、产品、版本和路径链接校验。
- 新增目录分隔符、目录越界及完整更新流程回归。在包含中文和空格的隔离目录中，通过无界面测试宿主验证真实准备、退出、备份、替换和重启，不操作用户的 DevUp 程序。

如果旧版已出现上述错误，请先关闭 DevUp，手动下载本版 DevUp.exe 并覆盖原文件一次，保留 DevUpData 目录。旧版执行替换前会被自身的错误校验拦截，仅重复自动更新无法安装这项修复。手动覆盖后可使用修复后的自动更新流程。

仅分发 DevUp.exe，适用于 Windows 10 19041+ / Windows 11 x64，需要官方 .NET 8 Desktop Runtime（x64）。
