新增自启动管理，并将清理规则与排除规则统一内嵌到单个 DevUp.exe。垃圾清理页面先扫描，再显示实际发现的可清理项目。

- 自启动管理覆盖 Run/RunOnce 注册表、用户及公共启动目录、开机/登录计划任务和第三方自动或触发启动服务。支持搜索、多选禁用、恢复及同一确切程序路径的关联入口操作。
- 禁用修改真实系统配置，操作前保存原配置，操作后重新读取来源逐项确认；配置变化、权限不足或部分失败会明确报告。Windows 维护任务和受保护服务只展示。
- 清理及排除规则随程序一起更新，不再分发或下载 DevUp.rules.json.gz。旧版下载的外部规则不会覆盖内嵌规则。
- 清理页在扫描前保持空列表；扫描完成后仅展示有候选文件的项目，扫描取消、失败或空结果均不能直接清理。

仅分发 DevUp.exe，适用于 Windows 10 19041+ / Windows 11 x64，需要官方 .NET 8 Desktop Runtime（x64）。设置、日志、备份等运行数据仍保存在程序旁的 DevUpData。

发布验证：Release 编译、原有回归、自启专项检查及本地 WPF 界面检查。自启配置测试仅操作唯一命名的测试入口。当前普通权限环境已验证用户注册表、启动文件的禁用与恢复及任务扫描；系统级任务和服务修改、UAC 取消、实际重启效果仍需管理员环境验证。Store StartupTask、驱动、策略等机制不在本次管理范围，软件仍可能重新注册自启入口。
