改进检查结果的可信度、软件搜索与多选升级，以及批量失败后的继续处理。

- 设备、驱动更新和软件更新分别记录检查状态与上次成功时间。尚未成功检查时显示「—」，成功检查后才显示零；失败、取消或需要重新检查时保留并标注上次结果。JSON / HTML 报告同步包含模块检查状态。
- 软件页支持按名称、发布者和 winget 包 ID 搜索。使用复选框选择当前筛选结果、清空勾选或升级选中项，并提示筛选之外的已勾选数量。「全部升级」明确包含筛选外的更新，排除已忽略项。
- 批量升级保留逐项成功、失败、取消、尚未执行及跳过的结果，支持重试失败项、继续未执行项和复制完整结果。重试和继续前重新读取清单与更新，避免重复升级成功项目，跳过已无可升级项的软件。
- 结果面板可折叠，较小窗口默认显示结果汇总；软件名称列设置最小宽度，窄窗口支持横向滚动。
- 批量结果保留在当前会话，开始新批次会替换上一批结果，退出程序后不保留。

仅分发 DevUp.exe，适用于 Windows 10 19041+ / Windows 11 x64，需要官方 .NET 8 Desktop Runtime（x64）。设置、日志及备份继续保存在程序旁的 DevUpData。
